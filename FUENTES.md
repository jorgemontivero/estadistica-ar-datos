# De dónde se baja cada fuente

Los microdatos **no están en este repositorio**. Cada organismo los
publica por su cuenta, con su propia licencia y sus propias
condiciones de uso, y redistribuirlos acá sería crear una copia que
queda vieja y de la que nadie se hace cargo.

La tabla es el catálogo de fuentes de
[estadistica.ar/fuentes](https://estadistica.ar/fuentes), donde cada
una tiene además su ficha con las advertencias de uso: qué variables
engañan, qué totales no cierran y qué cambió entre ediciones.

## Dónde ponerlos

Los generadores buscan los archivos en la carpeta que indique la
variable de entorno `DATOS_AR`, y si no está, en `datos-fuente/`
dentro de este repositorio —que está ignorada por git—.

```bash
export DATOS_AR="/donde/tengas/los/microdatos"   # Linux y macOS
$env:DATOS_AR = "D:\Datos"                       # PowerShell
```

La estructura de subcarpetas que esperan los scripts es la del
organismo: `INDEC/EPH/01_microdatos_eph/…`, `Salud/DEIS/…`. Cada
generador declara arriba de todo la ruta exacta que necesita.
